🔢 What is a Number Base?

Every day you use Base 10 (decimal) — 10 digits: 0-9. When a column reaches 10, it "rolls over" and carries 1 to the next column.

A number in any base b only uses digits from 0 to (b−1). Example: Base 5 only uses 0,1,2,3,4.

Think of it like a car's mileage odometer — each wheel/plate can only show digits 0 to (base−1). Once a plate completes a full cycle, it pushes the next plate by 1.
